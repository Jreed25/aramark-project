## 1. Introduction

Understanding customer spending behavior is critical for businesses to optimize operations, improve customer targeting, and increase profitability. This project analyzes a large-scale dataset provided by Aramark–Avendra, which includes detailed information on customer transactions across various industries in the United States.

The goal of this analysis is to identify patterns in spending behavior across product categories, geographic locations, and business types. By uncovering these patterns, the project aims to generate actionable insights that can support business decision-making.

## 2. Objectives

The primary objectives of this project are:

- To analyze how spending is distributed across product categories
- To identify key factors that influence customer spending
- To explore geographic variations in spending behavior
- To compare spending patterns across different business entity types
- To evaluate the impact of ecommerce adoption on customer spending

## 3. Dataset Description

The dataset consists of transactional spending records for customers across the United States. Each record includes information about the customer, location, product category, and total spending.

Key features include:

- **Category Levels (1–4):** Hierarchical classification of products
- **Geographic Data:** City, state, and ZIP code
- **Business Entity Type:** Industry classification (e.g., hotel, restaurant, healthcare)
- **Ecommerce Status:** Indicates whether the customer uses the ecommerce platform
- **Spend Random Factor:** Total spend in USD 

This dataset enables analysis of spending behavior across multiple dimensions.

## 4. Methodology

The analysis will be conducted in several stages:

1. **Data Exploration (EDA):**
   - Inspect dataset structure and variables
   - Identify missing values and clean data
   - Analyze spending patterns across categories, locations, and business types

2. **Visualization:**
   - Use charts to highlight trends and comparisons

3. **Advanced Analysis (Planned):**
   - Customer segmentation using clustering techniques
   - Predictive modeling to estimate future spending
   - Association rule mining for identifying product relationships

All analysis will be performed using Python and data analysis libraries such as pandas and matplotlib.
