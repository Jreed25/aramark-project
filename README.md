# Aramark–Avendra Spend Analysis

## Overview
This project analyzes customer spending data provided by Aramark–Avendra to identify patterns across product categories, geographic locations, and business types.

## Objectives
- Analyze spending distribution across categories
- Identify key drivers of customer spend
- Explore geographic trends in spending
- Compare behavior across business types
- Evaluate the impact of ecommerce usage

## Dataset
The dataset contains transactional spending data across U.S. customers, including:
- Customer information
- Product category hierarchy (Level 1–4)
- Geographic data (city, state)
- Business entity type
- Ecommerce status
- Total spend (Spend Random Factor)

## Project Structure
- `notebooks/` – EDA and analysis
- `docs/` – notes and report drafts
- `results/` – outputs and visualizations
- `src/` – reusable code (if needed)
